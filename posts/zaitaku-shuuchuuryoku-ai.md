在宅ワークの最大の敵は、上司の目ではなく「自分の集中力」です。この記事では、**AIを監視役ではなく“タスクの切り分け役”として使い、在宅での集中力を維持する方法**を紹介します。

## 前提:AIはあなたを監視してくれない

最初にはっきりさせておくと、AIは「サボっていないか見張る」ことはできません。**できるのは「今やるべきことを小さく具体的にする」こと**です。この考え方は[AIに「やる気が出ない日の過ごし方」を聞いたら](yaruki-denai-hi-ai.html)で紹介した「タスクを小さく分解する」アプローチの延長線上にあります。

## 実践1:朝一番に「今日やることリスト」を作らせる

```
今日やるべきタスクは以下です。優先順位をつけて、
それぞれ「何分でできそうか」の見積もりも付けてください。

・(タスク1)
・(タスク2)
・(タスク3)
```

見積もり時間が入ると、「午前中にここまで」という区切りが作りやすくなります。

## 実践2:作業前に「25分でやること」を宣言する

ポモドーロ・テクニック(25分作業+5分休憩)とAIの相性は良好です。

```
これから25分、〇〇の作業に集中します。
25分で終わらせるべき最小限のゴールを1つだけ提案してください。
```

「1つだけ」と指定するのがポイントです。欲張って複数タスクを詰め込むと、集中力がかえって分散します。

## 実践3:気が散った時の「立て直しプロンプト」

```
今、〇〇が気になって集中が切れました。
5秒でできる仕切り直しの行動を1つ教えてください。
```

「深呼吸する」「席を立って戻る」など、AIが即座に小さな行動を返してくれるので、**自己嫌悪に沈む前に次の行動に移れる**のが利点です。

## 実践4:1日の終わりに振り返りを頼む

```
今日やったこと・やれなかったことを伝えます。
明日に活かせる改善点を1つだけ教えてください。

やったこと:
やれなかったこと:
```

「1つだけ」と絞ることで、反省が長文の自己批判にならずに済みます。

## それでもAIだけでは解決しないこと

- **物理的な誘惑(スマホ・通知)**:AIに相談するより、通知オフや別室への移動など環境側の対策が効果的
- **慢性的な集中力低下**:睡眠不足や体調不良が原因のことも多く、その場合はAIより生活習慣の見直しが先です
- **家族・同居人がいる環境の音や声かけ**:これはAIでは解決できません。[AIに家事分担・タスク管理を相談してみた](kaji-buntan-taskkanri-ai.html)のように、同居人との事前の取り決めが有効です

## スマホ版でも同じ使い方ができる

外出先や気分転換に場所を変えて作業する時も、スマホのAIアプリで同じプロンプトが使えます。詳しくは[スマホだけでできるAI活用術](sumaho-ai-katsuyou.html)を参照してください。

## まとめ

- AIは監視役ではなく「タスクを小さく切り分ける相棒」として使う
- 25分単位の宣言と、気が散った時の立て直しプロンプトが実用的
- 物理的な誘惑や慢性的な不調は、AIより環境・生活習慣の見直しが優先

明日の朝、パソコンを開く前にまず「今日やることリスト」をAIに作らせてみてください。1日の始まり方が変わります。
