9月に入ると、異業種交流会や勉強会が増え、名刺がどんどん溜まっていく時期になります。「もらった名刺、結局そのまま放置…」を防ぐために、AIを使った整理方法と、**必ず押さえておくべき注意点**をまとめました。

## 最初に:これだけは絶対に守ってほしいこと

**名刺の写真をそのまま外部のAIチャットに送るのはおすすめしません。** 名刺には氏名・会社名・電話番号・メールアドレスなど、**あなた自身ではなく「相手」の個人情報**が書かれています。自分の情報を入力する場合とはリスクの重さが違います。

[生成AIに入力してはいけない情報まとめ](ai-nyuryoku-kikenjouhou.html)で紹介した「他人に見られて困る情報は入れない」という原則は、**自分の情報以上に、他人の情報にこそ厳しく適用すべき**です。

## 安全な進め方

### ステップ1:名刺のデータ化は専用アプリを使う
名刺をテキストデータにする作業自体は、**名刺管理専用のアプリ・サービス**を使うのが基本です。専用サービスは個人情報の取り扱いについて業として整備されていることが多く、汎用AIチャットに直接送るより安全です。どのサービスが自分の用途に合うかは、各社の公式サイトで機能・プライバシーポリシーを確認してください。

### ステップ2:整理・分類の相談はAIチャットに任せる
専用アプリでデータ化した後、**「どう分類するか」「フォローアップの優先順位をどうするか」といった、個人情報そのものを含まない相談**であれば、AIチャットに頼るのが安全です。

```
交流会でお会いした方々を、以下の軸で分類したいです。
・今後の仕事につながりそうな方
・情報交換を続けたい方
・特に急ぎではない方

分類の考え方の例を、優先順位のつけ方も含めて提案してください。
```

**具体的な氏名・会社名を書かずに、「どう考えればいいか」だけを相談する**のがポイントです。

### ステップ3:フォローアップメールの下書きはテンプレートで
個別の相手情報を伏せたまま、**汎用的なテンプレート**をAIに作らせ、後から自分で宛名や内容を差し込む方法が安全です。

```
交流会でお会いした方へのお礼メールのテンプレートを作ってください。
・当日お話しした内容に軽く触れる一文を【 】で入れられるようにしてください
・堅すぎず、かといって馴れ馴れしくない、丁寧な文体で
```

メール作成の基本プロンプトは[ビジネスメールをAIに書かせる時のプロンプト集](ai-mail-prompt.html)も参考にしてください。

## AIに任せられること・任せられないこと

| 任せられること | 任せられないこと |
| --- | --- |
| 分類・優先順位づけの考え方の相談 | 個人情報そのものの入力・処理 |
| フォローアップメールのテンプレート作成 | 相手の個人情報を含む具体的な文面の丸投げ |
| 名刺整理の運用ルールづくりの壁打ち | 名刺データそのものの外部AIへのアップロード |

## それでも大事なのは「早めのフォロー」

交流会の効果は、**会った直後(1週間以内)にフォローできるかどうか**で大きく変わります。AIはあくまで「テンプレート作り」「優先順位の整理」を手伝ってくれるだけで、**実際に連絡するかどうかの判断と実行は人間の仕事**です。

## まとめ

- 名刺の個人情報を汎用AIチャットに直接入力しない。データ化は専用アプリで
- AIに任せるのは「分類の考え方」「テンプレート作成」など、個人情報を含まない部分に限定する
- 交流会シーズン前に、フォローアップの型だけでも先に用意しておくと動きが早くなる

9月の交流会シーズンが始まる前に、まずは「個人情報を入れずに使える」フォローアップメールのテンプレートだけ、AIと一緒に作っておいてください。
