忘年会・新年会シーズンの幹事は、地味に仕事が多いものです。人気のお店は1〜2か月前から埋まり始めるため、準備が動き出すのは今ごろから。この記事では、**幹事の仕事のうち、AIに任せられる部分と自分で確認すべき部分**を整理します。

## 幹事の仕事を分解してみる

| 仕事 | AIに任せやすさ |
| --- | --- |
| 店選びの「基準」づくり | ◎ 得意 |
| 参加者への案内メール・メッセージ | ◎ 得意 |
| 日程調整の進め方・候補日の出し方 | ○ 補助できる |
| 当日の進行表・乾杯の挨拶案 | ◎ 得意 |
| 具体的なお店の選定・予約・価格確認 | × 自分でやる |

ポイントは、**「お店そのものの情報」はAIに頼らず、「考え方・文章・段取り」を手伝ってもらう**ことです。AIが挙げるお店の名前や価格、空席状況は古い、あるいは実在しない可能性があるため(参考:[AIのハルシネーション](ai-hallucination-minuku.html))、必ず予約サイトや店舗の公式情報で確認してください。

## ステップ1:店選びの「基準」を作ってもらう

```
忘年会の幹事をします。お店を探す前に、選ぶ基準を整理したいです。
・人数:12人前後
・予算:一人5,000円程度
・参加者の特徴:年代はバラバラ、お酒を飲まない人も数名いる
・場所:職場の最寄り駅から歩ける範囲

確認すべき項目(個室の有無、飲み放題の条件、アレルギー対応、
ソフトドリンクの充実度など)を、優先度順にチェックリストにしてください。
お店の名前は挙げなくて構いません。
```

**「お店の名前は挙げなくて構いません」と先に伝える**のがコツです。基準のチェックリストさえあれば、あとは候補店を見比べる作業が一気に楽になります。

## ステップ2:案内メール・メッセージを作る

```
忘年会の案内メールを作ってください。
・日時と場所は【 】で空欄にしておいてください
・出欠の返事の期限も【 】で空欄に
・参加費は一人【 】円
・堅すぎず、かといってくだけすぎない職場向けのトーンで
・お酒を飲まない方も気兼ねなく参加できる一文を入れてください
```

日時・場所などの**確定情報は空欄にしておき、自分で差し込む**のが安全です。案内文の頼み方の基本は[ビジネスメールをAIに書かせる時のプロンプト集](ai-mail-prompt.html)と同じです。

## ステップ3:日程調整の進め方を整理する

```
参加者12人の日程調整をします。幹事の負担を減らすために、
候補日の出し方と、返事を集めるときの工夫を教えてください。
```

日程そのものはAIが決められませんが、**「候補日は3つまで」「返事の期限を先に決める」**といった進め方の工夫を提案してもらえます。時間配分の考え方は、[AIに1日のスケジュール管理を丸ごと任せてみた](schedule-kanri-ai.html)で紹介した「条件を伝えて組んでもらう」方法が応用できます。

## ステップ4:当日の進行表・挨拶案

```
2時間の忘年会の進行表の叩き台を作ってください。
・乾杯の挨拶(30秒程度)の案を2パターン
・中締めのタイミングと一言の案
```

挨拶の文面は、[AIで暑中見舞い・年賀状の文面を作る方法](shochu-nenga-ai-bunmen.html)で紹介した「相手・内容・トーンを伝える」頼み方がそのまま使えます。**最後に、一言だけ自分の言葉を足す**と、定型文っぽさが消えます。

## 注意点

### ① 参加者の個人情報は入力しない
氏名や、アレルギー・持病・宗教上の事情など**個人に関わる情報は入力しません**。「お酒を飲まない人が数名」「アレルギー対応が必要な人がいる」のように、属性だけを伝えれば十分です(参考:[生成AIに入力してはいけない情報まとめ](ai-nyuryoku-kikenjouhou.html))。

### ② お店の情報は必ず自分で確認する
価格・メニュー・個室の有無・予約条件は、予約サイトやお店の公式情報で確認します。

### ③ 参加の同調圧力に配慮する
「全員参加が前提」の文面にならないよう、**不参加でも気まずくならない一文**を入れておくと、参加者にとっても安心です。

## まとめ

- 幹事の仕事のうち、「基準づくり・案内文・進行表」はAIが得意、「お店の選定・予約・価格確認」は自分の仕事
- 日時・場所・金額などの確定情報は空欄にして、自分で差し込む
- 参加者の個人情報は入力せず、属性だけ伝える

まずは「人数・予算・お酒を飲まない人がいるか」の3点をメモして、店選びの基準チェックリストをAIに作ってもらうところから始めてみてください。
