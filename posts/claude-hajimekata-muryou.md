文章の自然さや長い資料の扱いやすさで名前が挙がることの多いAIアシスタント「Claude」。この記事では、初めて使う人向けに**始め方と、最初に試したい頼み方**をまとめます。ChatGPTの始め方は[ChatGPTの始め方:登録から最初の質問まで](chatgpt-hajimekata-shoshinsha.html)で紹介しているので、あわせて参考にしてください。

> ※画面の表記・登録方法・無料版の利用範囲は更新されることがあります。具体的な内容は、公式サイトの案内を優先してください。

## ステップ1:公式サイトから始める

ChatGPTと同じく、まずは**公式のサイトやアプリを使う**ことが大切です。

- 検索結果の広告やSNSのリンクではなく、**運営元の公式サイト([Claude](https://claude.ai/))から入る**
- アプリは、ストアで**提供元の表示を確認**してからインストールする
- 「今だけ無料で全機能」のような誘い文句の案内は避ける

## ステップ2:登録して、無料版で試す

公式サイトの案内に沿って登録します。まずは**無料版で十分に試してから**、必要になったら有料プランを検討するのが安全です。無料版でできる範囲・回数の制限は変わるため、公式サイトで確認してください。有料にする目安は[Claude Proを1ヶ月使ってわかったこと](claude-pro-1kagetsu.html)にまとめています。

登録時に求められる情報が、無料で始めるだけなのに多すぎないか、**有料プランの申し込み画面と混同していないか**も確認してください。

## 最初に試したい5つの頼み方

難しい指示は要りません。ふだんの仕事や生活で「ちょっと面倒」なことを、そのまま頼んでみてください。

### ① 文章の推敲
```
次の文章を、意味は変えずに、読みやすい丁寧な文章に直してください。
(文章を貼る)
```

### ② 長めの文章の要約
```
次の文章を、重要なポイント3つに絞って要約してください。
(文章を貼る)
```
長文の扱いは、[AIで長いPDFを3分で要約する方法](ai-pdf-youyaku.html)も参考になります。

### ③ メールの下書き
```
取引先への日程変更のお願いメールの下書きを作ってください。日時は【 】にしておいてください。
```
頼み方の例は[ビジネスメールをAIに書かせる時のプロンプト集](ai-mail-prompt.html)にまとめています。

### ④ アイデア出し
```
来月の部署の懇親会の企画案を5つ、予算5,000円以内で考えてください。
```

### ⑤ 考えの整理(壁打ち)
```
最近、仕事の優先順位がつけられず困っています。質問をしながら、私の状況を整理する手伝いをしてください。
```
こうした相談は、[AIに仕事の愚痴を相談したら意外と有能だった話](shigoto-guchi-ai-soudan.html)でも試しています。

## ChatGPTとの違いは?

「どちらが優れているか」は、使う目的で変わります。文章の雰囲気の好みや、使える機能の範囲は、**サービスごとに違い、アップデートでも変わります**。詳しい比較は、[ChatGPTとClaudeはどっちを使うべき?](chatgpt-claude-hikaku.html)と[同じ依頼をChatGPT・Claude・Geminiに出して比較してみた](chatgpt-claude-gemini-hikaku.html)を参考にしつつ、最終的には**同じ依頼を両方に出して、自分の仕事で比べる**のが確実です。

## 使い始める前の注意点

### ① 入力してはいけない情報がある
個人情報、パスワード、会社の機密情報などは入力しません。迷ったら「他人に見られて困る情報は入れない」を基準にしてください(参考:[生成AIに入力してはいけない情報まとめ](ai-nyuryoku-kikenjouhou.html))。

### ② データの扱いの設定を確認する
入力内容が学習に使われるかどうかなど、**データの扱いの設定**は、使い始める前に確認しておくと安心です(参考:[AIに入力したデータは学習に使われる?オプトアウト設定の確認方法](ai-opt-out-settei.html))。

### ③ 間違いを言うこともある
どのAIも、**もっともらしい間違いを答える**ことがあります。数字や固有名詞は必ず自分で確認してください(参考:[AIのハルシネーション](ai-hallucination-minuku.html))。

## 慣れてきたら

複数の案件を並行して進めるようになったら、[ClaudeのProjects機能で案件ごとの文脈を管理してみた](claude-projects-katsuyou.html)のように、会話を整理する機能も試してみてください。頼み方の基本は、[プロンプトの基本「役割・条件・形式」の3点セット](prompt-kihon-3ten.html)が役に立ちます。

## まとめ

- 公式サイトから入り、まずは無料版で試して、有料にするかは後から決める
- 最初は「推敲・要約・メール・アイデア出し・壁打ち」のような身近な頼みごとから始める
- ChatGPTとの優劣は目的次第。入力する情報の注意と、事実確認は、どのAIでも共通

まずは、今日書く予定のメールや文章を1つ、Claudeに下書きしてもらうところから始めてみてください。
